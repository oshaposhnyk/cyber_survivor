# 🛸 Cyber Survivor: Protocol Zero (Кібер-Сурвайвор: Протокол Нуль)

> **Навчальний проект прототипу гри на Godot Engine 4**  
> *Тематика:* Наукова фантастика, космічна станція, бойові роботи та андроїди.  
> *Жанр:* Космічний Survivor-like (аналог Vampire Survivors) з **відкритим деревом технологій**, комбінаціями-синергіями та хвилями ворогів.  
> *Платформи:* Desktop (Godot Editor / PC) та **Web HTML5 (готово до запуску в браузері та GitHub Pages)**.

---

## 🌟 1. Концепція та Сюжет

Події розгортаються на орбітальній станції глибокого космосу *"Aethelgard Core"*. Штучний інтелект комплексу уражений руйнівним кодом **«Протокол Нуль»**, через що весь персонал автоматонів, шахтарських ботів і штурмових мехів збунтувався.

Гравець керує експериментальним бойовим андроїдом **ARC-01 (Cybernetic Vanguard)**. Мета — вижити в центрі орбітальної станції, стримувати масивні хвилі бойових машин, добувати нанітний брухт, модернізувати бортові системи через **Технологічну Матрицю** та активувати руйнівні синергії зброї.

## 🚀 3. Ключові Особливості та Відмінності від Vampire Survivors

1. **Відкрите Дерево Технологій замість Випадкового Вибору (No RNG Perks):**
   - У класичних рогаликах гравець щоразу обирає 1 з 3 випадкових карток.
   - У **Cyber Survivor: Protocol Zero** реалізовано повноцінне **візуальне відкрите дерево розвитку (Tech Matrix)** із трьома гілками. Гравець сам обирає свою стратегію: швидкість, важку броню, далекобійні рейлгани чи ланцюгові блискавки.
2. **Система Технологічних Синергій (Комбінації та Еволюції):**
   - При дослідженні певних взаємопов'язаних навичок відкриваються унікальні пасивні та активні синергії, що кардинально змінюють роботу систем.
3. **Кіберпанк Дерево Навичок та Інспектор Телеметрії:**
   - Інтерфейс у вигляді плати мікросхем (PCB Circuit Board) з анімованими енергетичними імпульсами по шинах живлення.
   - Візуальні кібер-піпи прогресу рівнів (`[■■■□□]`), технічні коди (`[WPN-01]`, `[DEF-02]`, `[OVC-03]`) та спеціальні піктограми підсистем.
   - Бічна панель нейронного інспектора для вивчення характеристик, наступних рівнів та матричних синергій.
4. **Адаптивний Аудіо-Директор (Smart Sound Limiter):**
   - Професійні звуки наукової фантастики (Kenney Sci-Fi Audio) з розумним тротлінгом частоти відтворення: запобігає перевантаженню Web Audio буфера в браузері при одночасній загибелі сотень ворогів.
   - Мультиплікатор пітчу при зборі нанітного брухту: кожна наступна деталь звучить вище за шкалою, створюючи аркадний комбо-ефект.
5. **Роботизована Космічна Тематика:**
   - Вороги — це дрони, крокуючі павуки, бойові стрілецькі андроїди, дрони-самогубці та мехи-титани.
   - Ефекти силових полів, лазерні спалахи, тахіонні промені, нанітні ремонтні поля, EMP-хвилі.
6. **Хвильовий Директор Секторів:**
   - 5 послідовних етапів із наростанням щільності ворогів, появою босів-мехів та фінальним випробуванням виживання.
7. **Повна Web / HTML5 сумісність:**
   - Гра скомпільована без вимоги SharedArrayBuffer (single-threaded compatibility build), тому запускається на будь-якому статичному хостингу (зокрема **GitHub Pages**) без складних налаштувань серверних заголовків.

## ⚡ 4. Технологічна Матриця (Дерево Розвитку)

Дерево налічує 12 унікальних технологій, розподілених за 3 гілками:

### ⚔️ Гілка I: Озброєння (Offense)
1. **Імпульсний Бластер (Pulse Blaster)** — *Рівні 1-5*  
   - Базова скорострільна плазмова гармата.
   - *Ефект:* +20% шкоди, +1 снаряд на 3-му і 5-му рівнях, скорочення перезарядки.
2. **Мікро-Ракети (Micro-Missiles)** — *Рівні 1-4 (Вимога: Бластер Рів. 1)*  
   - Залп самонавідних ракет, що самостійно шукають цілі та детонують з AoE-радіусом.
   - *Ефект:* +1 ракета за рівень, +25% радіус вибуху.
3. **Рейлган Пробивач (Railgun Piercer)** — *Рівні 1-4 (Вимога: Бластер Рів. 2)*  
   - Надзвуковий тахіонний промінь колосальної потужності, що прорізає натовпи ворогів наскрізь.
   - *Ефект:* +40% шкоди, пробиває шеренгу ворогів.
4. **Орбітальні Дрони (Orbital Defense Drones)** — *Рівні 1-4 (Вимога: Ракети Рів. 2)*  
   - Автономні дрони-сателіти, що постійно кружляють навколо андроїда, нищать ворогів контактом та допоміжним лазерним вогнем.

### 🛡️ Гілка II: Кібернетика та Захист (Defense)
1. **Силове Поле (Force Field Shield)** — *Рівні 1-5*  
   - Енергетичний бар'єр навколо андроїда, що бере на себе всю шкоду перед корпусом.
   - *Ефект:* +35 ємності щита, зменшення затримки відновлення.
2. **Нанітне Відновлення (Nanite Repair Matrix)** — *Рівні 1-4 (Вимога: Щит Рів. 1)*  
   - Колонія ремонтних нанітів, які безперервно лагодять мікротріщини в обшивці андроїда.
   - *Ефект:* +2.2 HP щосекундної постійної регенерації.
3. **Магнітний Захоплювач (Magnetic Scrap Collector)** — *Рівні 1-3 (Вимога: Щит Рів. 1)*  
   - Гравітаційний магніт для притягання розсипаного ворожого брухту та енергоядер.
   - *Ефект:* +50% до радіусу збору на рівень.
4. **Титанова Броня (Titanium Armor Plating)** — *Рівні 1-4 (Вимога: Наніти Рів. 2)*  
   - Посилені композитні пластини корпусу.
   - *Ефект:* -12% вхідної шкоди від усіх атак, +35 до максимального запасу здоров'я (HP).

### ⚡ Гілка III: Оверклокінг та Електроніка (Overclock)
1. **Серво-Оверклокінг (Thruster Overclock)** — *Рівні 1-4*  
   - Форсування маневрових дюз та сервоприводів.
   - *Ефект:* +18% до швидкості пересування андроїда.
2. **Тактовий Прискорювач (Overclock Core)** — *Рівні 1-4 (Вимога: Швидкість Рів. 1)*  
   - Збільшення частоти обчислювального блоку.
   - *Ефект:* -12% часу перезарядки (cooldown) для всіх видів озброєння.
3. **EMP Детонатор (EMP Shockwave)** — *Рівні 1-4 (Вимога: Прискорювач Рів. 2)*  
   - Періодичний викид кругової електромагнітної хвилі, що паралізує ворогів і спалює їхні плати.
   - *Ефект:* +30% радіус, +40 шкоди, оглушення на 2-4 секунди.
4. **Плазмовий Провідник (Plasma Conductor)** — *Рівні 1-3 (Вимога: EMP Рів. 2)*  
   - Перевантаження снарядів плазмою.
   - *Ефект:* Усі попадання створюють ланцюгову блискавку, яка перекидається на сусідніх роботів.

## ✨ 5. Матриця Синергій (Комбінації)

| Синергія | Необхідні навички | Унікальний бойовий ефект |
|---|---|---|
| **⚡ Плазмовий Шторм** | `Бластер` ≥ 3 + `Провідник` ≥ 1 | Бластер випускає каскадний потрійний залп, снаряди пробивають цілі та б'ють ланцюговою блискавкою по 3 ворогах! |
| **💥 Апокаліптичний EMP** | `Силове Поле` ≥ 3 + `EMP` ≥ 2 | При пробитті силового поля або кожні 10 сек відбувається надпотужний EMP-вибух на весь екран, що миттєво знищує дрібних дронів! |
| **🚀 Рій Валькірія** | `Мікро-Ракети` ≥ 3 + `Рейлган` ≥ 2 | Ракети оснащуються рейлгановими прискорювачами: пронизують ворогів наскрізь і детонують подвійним ядерним вибухом! |
| **🛡️ Нанітний Бастіон** | `Наніти` ≥ 3 + `Дрони` ≥ 2 | Дрони утворюють захисний енергетичний контур: спалюють усіх ворогів у периметрі та втричі прискорюють регенерацію здоров'я! |

2. **Бойовий Бот-Павук (Spider Bot):**  
   - *HP:* 45 | *Швидкість:* 125 | *Шкода:* 12  
   - Рухається зигзагоподібною траєкторією, важче влучити.
3. **Штурмовий Андроїд (Assault Android):**  
   - *HP:* 80 | *Швидкість:* 95 | *Шкода:* 15  
   - Тримає середню дистанцію і веде прицільний вогонь червоними лазерами.

   - *HP:* 30 | *Швидкість:* 190 | *Шкода:* 35 (AoE)  
   - При наближенні блимає червоним аварійним сигналом і детонує потужним вибухом.
5. **Важкий Крокуючий Мех-Титан (Heavy Mech Walker) — Міні-бос:**  
   - *HP:* 450 | *Швидкість:* 60 | *Шкода:* 25

## 💻 9. Як запустити проект

### Варіант А: Запуск у браузері для викладача (GitHub Pages)
1. Створіть репозиторій на GitHub та завантажте туди проект:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Cyber Survivor prototype"
   git remote add origin https://github.com/<ваш_логін>/<назва_репозиторію>.git
   git push -u origin main
   ```
2. У налаштуваннях репозиторію GitHub перейдіть:
   `Settings` -> `Pages` -> у розділі **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: `main` / folder: `/docs`
   - Натисніть **Save**.
3. За 1-2 хвилини гра буде доступна за посиланням:
   `https://<ваш_логін>.github.io/<назва_репозиторію>/`  
   Викладач зможе відкрити гру в Google Chrome, Safari, Firefox або Edge без жодного встановлення стороннього софту!

### Варіант Б: Запуск локального веб-сервера з папки `docs/`
Якщо потрібно швидко перевірити роботу Web-білду на своєму комп'ютері:
```bash
python3 -m http.server 8000 --directory docs
```
Відкрийте в браузері: `http://localhost:8000`

### Варіант В: Запуск у Godot Engine 4
1. Відкрийте Godot Engine 4 (версія 4.2+ або 4.7+).
2. Натисніть **Import** та виберіть файл `project.godot` у цій папці.
3. Натисніть кнопку **Run Project (F5)** або **Run Current Scene (F6)**.
