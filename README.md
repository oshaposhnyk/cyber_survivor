# 🛸 Cyber Survivor: Protocol Zero (Кібер-Сурвайвор: Протокол Нуль)

> **Навчальний проект прототипу гри на Godot Engine 4**  
> *Тематика:* Наукова фантастика, космічна станція, бойові роботи та андроїди.  
> *Жанр:* Космічний survivor-like шутер з **відкритим деревом технологій**, доктринами, синергіями та хвилями ворогів.  
> *Платформи:* Desktop (Godot Editor / PC) та **Web HTML5 (готово до запуску в браузері та GitHub Pages)**.

---

## 🌟 1. Концепція та Сюжет

Події розгортаються на орбітальній станції глибокого космосу *"Aethelgard Core"*. Штучний інтелект комплексу уражений руйнівним кодом **«Протокол Нуль»**, через що весь персонал автоматонів, шахтарських ботів і штурмових мехів збунтувався.

Гравець керує експериментальним бойовим кораблем **ARC-01 (Cybernetic Vanguard)**. Мета — протриматися 7 хвилин, стримувати хвилі бойових машин, збирати нанітний брухт, модернізувати системи через **Технологічну Матрицю** та активувати синергії зброї.

## 🚀 3. Ключові Особливості

1. **Відкрите Дерево Технологій замість Випадкового Вибору (No RNG Perks):**
   - Замість вибору 1 з 3 випадкових карток гравець сам прокачує **візуальне відкрите дерево (Tech Matrix)** з п'ятьма гілками.
2. **Доктрини:** гілка з найбільшою кількістю очок (від 4) визначає стиль гри: сильний бонус і відчутний мінус.
3. **Синергії:** 8 комбінацій навичок кардинально змінюють роботу систем.
4. **Захист від снарядів у кожній гілці:** відбиття, перехоплення, злам, стирання, укриття (див. розділ 6).
5. **Чесний бій із стрільцями:**
   - не більше 5 ворогів цілиться або стріляє одночасно (жетони вогню);
   - перед чергою — червона лінія прицілювання 0.4 с;
   - ворожі снаряди повільні (285 px/с), від них можна ухилятися в польоті.
6. **Орди до 1100 ворогів у браузері:** вороги рендеряться через MultiMesh, без окремого вузла на кожного (див. розділ 9).
7. **Кіберпанк-інтерфейс:** дерево у вигляді плати мікросхем, коди систем (`[WPN-01]`, `[DEF-02]`), інспектор телеметрії, піпи рівнів `[■■■□□]`.
8. **Аудіо-директор:** звуки Kenney Sci-Fi з тротлінгом частоти, щоб не перевантажити Web Audio; висхідний пітч при зборі брухту.
9. **Мета-прогрес «Кібердека»:** нанітний банк між забігами, постійні апгрейди корпусу, швидкості, магніту, ривка та аварійного ребуту.
10. **Повна Web / HTML5 сумісність:** збірка без SharedArrayBuffer (single-threaded), працює на будь-якому статичному хостингу, зокрема **GitHub Pages**.

## 🤖 7. Бестіарій Ворогів

Базові значення на 0:00. HP ворогів зростає з часом до ×6.95 на 7:00 (плавна крива), контактна шкода — до ×1.84.

| Ворог | HP | Швидкість | Контакт | Поведінка |
|---|---|---|---|---|
| Дрон-розвідник | 18 | 175 | 8 | Легкий, нападає зграями. |
| Бот-павук | 38 | 135 | 10 | Рухається зигзагом. |
| Штурмовий андроїд | 75 | 105 | 14 | Тримає дистанцію; після лінії прицілювання дає чергу з 3 пострілів. |
| Дрон-камікадзе | 25 | 210 | 25 | Біля корабля блимає жовто-білим, показує кільце 90 px і вибухає (35 шкоди, росте з часом). |
| Щитоносець | 220 | 72 | 16 | Купол 190 px удвічі зменшує пряму шкоду союзникам; вірус і поля його ігнорують. |
| Мех-титан | 500 | 65 | 25 | Віяло з 3 снарядів після прицілювання; багатий лут. |

**Чемпіони** (кожні 34–48 с): ×3.5 HP, корона і смужка HP, при смерті — граві-маяк.
- **HASTE** — прискорює сусідів.
- **JAMMER** — у полі 280 px зброя корабля перезаряджається вдвічі повільніше.
- **MENDER** — лагодить звичайних ворогів поруч (не боса і не реактори).

**Дредноут «LEVIATHAN-01»** (2:30): бос з лазерними віялами, радіальними залпами, спіраллю та ескортом; дає квантове ядро.

**Об'єкти арени:**
- нестабільні реактори вибухають на 240 px і шкодять ворогам; зникають далі 1800 px;
- контейнери даних: утримуйте зону 7 с — очко навички, овердрайв і повний щит; зникають через 75 с без захоплення.

### Продуктивність
- **Рій без вузлів.** Звичайний ворог — об'єкт даних (`EnemyBase`, RefCounted). `Swarm` оновлює всіх в одному циклі й малює кожен тип одним `MultiMeshInstance2D` (тіла і тіні), лише в межах екрана.
- **Влучання без фізики.** Снаряди гравця і ворогів перевіряють відстані через просторову сітку `EnemyRegistry` (клітинка 128 px).
- **LOD.** Вороги поза екраном оновлюються кожен 3-й кадр.
- **Ліміти.** До 160 підбирань на землі (далі брухт зараховується одразу), обмежені вибухи і тексти шкоди, не більше 2 кроків фізики на кадр.
- **Результат у браузері:** 1100 ворогів — 56–77 FPS; повний білд на 6:40 — 70–84 FPS.

## 💻 10. Як запустити проект

### Варіант А: Запуск у браузері для викладача (GitHub Pages)
1. Створіть репозиторій на GitHub та завантажте туди проект:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Cyber Survivor prototype"
   git remote add origin https://github.com/<ваш_логін>/<назва_репозиторію>.git
   git push -u origin main
   ```
2. У налаштуваннях репозиторію GitHub перейдіть:
   `Settings` -> `Pages` -> у розділі **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: `main` / folder: `/docs`
   - Натисніть **Save**.
3. За 1-2 хвилини гра буде доступна за посиланням:
   `https://<ваш_логін>.github.io/<назва_репозиторію>/`  
   Викладач зможе відкрити гру в Google Chrome, Safari, Firefox або Edge без встановлення стороннього софту.

### Варіант Б: Запуск локального веб-сервера з папки `docs/`
```bash
python3 -m http.server 8000 --directory docs
```
Відкрийте в браузері: `http://localhost:8000`

### Варіант В: Запуск у Godot Engine 4
1. Відкрийте Godot Engine 4.7.
2. Натисніть **Import** та виберіть файл `project.godot` у цій папці.
3. Натисніть **Run Project (F5)**.

### Оновлення Web-збірки
```bash
godot --headless --path . --export-release "Web" docs/index.html
```
